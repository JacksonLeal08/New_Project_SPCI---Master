# Antigravity Skill: Modern Corporate & Luxury Web Design (2026)

## 1. Visual Identity & Typography (Corporate Trends)

- **Typography**: Utilize "Liquid Typography" and kinetic variable fonts that adapt to motion. Prioritize bold, expressive display type for headings and ultra-minimal grid-driven systems for body text.
- **Luxury Standard**: Implement "Cinematic Dark Mode" as the default for premium brands to provide depth to high-resolution photography.
- **Color Systems**: Use adaptive color schemes and "Liquid Glass" layering for depth without visual weight.

## 2. Advanced Components & UI Elements

- **Layouts (Bento Grids)**: Organize information using Bento Grid layouts to create visual rhythm and clean information architecture.
- **Modals & Overlays**: Design translucent, glassmorphism-based modals with smooth entry micro-animations.
- **Icons**: Transition from generic symbols to "micro-illustrated" icons that provide tiny moments of storytelling and handcrafted personality.
- **Tables**: Ensure data tables use tabular numerals for perfect financial alignment and include proper ARIA headers for accessibility.

## 3. Interaction & Spatial Design

- **Micro-interactions**: Every interactive element (modals, filters, CTAs) must have tactile feedback and be fully keyboard-navigable.
- **Spatial UX**: Integrate 3D elements and spatial design principles where appropriate, especially for product visualization in e-commerce.
- **Motion**: Use "scrollytelling" as a business tool to guide users through complex data or luxury brand narratives.

## 4. Design-to-Code Infrastructure (Tokens)

- **Design Tokens**: Treat all color, spacing, type, and motion values as dynamic data (Design Tokens) to ensure consistency across web and mobile. Use tokens like `color.icon.success` instead of hardcoded hex values.
